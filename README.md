# roadmap-task-tracker-cs
Task Tracker CLI project for [roadmap.sh](https://roadmap.sh/projects/task-tracker) made in C#

## How to run
- Install [.NET](https://learn.microsoft.com/en-us/dotnet/core/install/windows#choose-the-correct-runtime)
- Install dotnet-script: `dotnet tool install -g dotnet-script`
- Run on terminal (at the file's directory): `dotnet-script Program.csx`

## Commands

### 1 Clear console and exit program
- clear ✅
- exit ✅

### 2 Adding a new task
- add "Complete project" ✅

### 3 Updating and deleting tasks
- update 1 "Complete task management project" ✅
- delete 1 ✅

### 4 Marking a task as in progress or done
- mark-in-progress 1 ✅
- mark-done 1 ❌

### 5 Listing all tasks
- list ❌

### 6 Listing tasks by status
- list todo ❌
- list in-progress ❌
- list done ❌
